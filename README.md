# GladSkin — Практическая работа № 2

Проект продолжает сайт из ПР1: сохраняются пять страниц, логотип, название, меню и розовая цветовая палитра. На странице каталога изначально отображаются все товары. Поиск и фильтры помогают быстро оставить только подходящие позиции.

## Структура
- index.html — главная страница;
- catalog.html — поиск и подбор средств по названию, назначению, типу кожи и категории;
- product.html — подробная карточка выбранного товара;
- cart.html — корзина с сохранением выбранных товаров в `localStorage`;
- contacts.html — форма обратной связи;
- style.css — общие стили ПР1 и адаптивная компоновка;
- script.js — фильтрация, валидация форм, карточка товара, корзина и запрос `fetch`;
- images/ — логотип и изображения товаров.

## Запуск
1. Распакуйте архив.
2. Откройте папку GladSkin_site в Visual Studio Code.
3. Запустите index.html через расширение Live Server.
4. Для внешнего запроса используйте браузер с подключением к Интернету.

## Что реализовано в ПР2
- отображение полного каталога при первом открытии страницы;
- поиск локальных товаров без перезагрузки страницы;
- фильтрация одновременно по назначению, типу кожи и виду средства;
- сортировка и сброс условий;
- карточка товара открывается с данными именно выбранной позиции;
- добавление товара в корзину, изменение количества, удаление и очистка корзины;
- проверка формы обратной связи и формы оформления заказа с ошибками рядом с полями;
- асинхронный GET-запрос через fetch к Open Beauty Facts;
- состояния загрузки, пустого результата, ошибки сети и тайм-аута.

## Важные ограничения
Формы не отправляют данные на сервер, заказ не создаётся и не оплачивается. Корзина хранится в localStorage текущего браузера. Внешний источник используется только как справочная база. Текстовый поиск Open Beauty Facts в этом учебном проекте использует /cgi/search.pl, который официальная документация относит к legacy-интерфейсу.
