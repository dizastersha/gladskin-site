# GladSkin — практическая работа № 1

Учебный статический сайт интернет-магазина косметики (вариант 8).

## Состав сайта
- `index.html` — главная страница;
- `catalog.html` — каталог из 12 позиций, размеченные фильтр и сортировка (пока без обработки);
- `product.html` — подробная страница одного товара;
- `cart.html` — демонстрационная корзина;
- `contacts.html` — контактные данные и форма обратной связи (пока без серверной отправки);
- `style.css` — общие адаптивные стили на CSS Grid и Flexbox;
- `images/` — локальные изображения товаров (JPG/SVG) и логотип `images/logo.svg`, предоставленный для проекта.

## Запуск в Visual Studio Code
1. Распакуйте архив целиком.
2. В Visual Studio Code выберите **File → Open Folder** и укажите папку `gladskin_site`.
3. Откройте `index.html` и запустите его в браузере. Можно использовать расширение Live Server, если оно установлено.
4. Не перемещайте HTML-файлы отдельно от `style.css` и папки `images`.

## Иллюстрации товаров
Изображения оптимизированы для карточек каталога. Картинки являются учебными иллюстрациями. Цены служат примерами для учебного проекта.
